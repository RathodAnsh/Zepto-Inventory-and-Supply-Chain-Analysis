# Zepto Supply Chain & Inventory Analysis

### Project Overview
This project focuses on analyzing Zepto's supply chain and inventory data from a 2-month period (Jan-Feb 2025) using Microsoft Power BI. The goal was to transform raw operational data into clear business insights, focusing on improving delivery efficiency and inventory management.

### Tools & Techniques Used
* **Power Query Editor** for extensive data cleaning, handling data errors, and creating calculated columns.

* **DAX (Data Analysis Expressions)** for building crucial business measures like `On-Time Delivery %` and `Stock Status`.

* **Interactive Dashboards** with slicers and cross-filtering to allow for deep-dive analysis.

### Key Insights
* Identified a critical service failure with an **On-Time Delivery Rate of only 20.10%**.

* Pinpointed a major cause for delays: a mismatch between staff schedules and **two major order peaks (midnight and evening hours)**.

* Flagged **256 products at immediate risk of stockout**, directly impacting sales.

* Discovered that **over ₹479K was lost to returns** due to internal failures (Damaged & Stale items), not a single rider's fault.

### Conclusion
This project provided valuable hands-on experience in building a complete Power BI solution from start to finish. It strengthened my ability to diagnose data quality issues, create meaningful KPIs, and present complex findings in a simple, story-driven format. The dashboards successfully turned raw data into a clear action plan for management.
